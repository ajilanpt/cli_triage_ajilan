# Decision — dataset choice

## Candidates

| Dataset | Publisher | Licence | Obligation |
|---|---|---|---|
| FlakeFlagger | Zenodo record 4450723 | CC-BY-4.0 | Attribution required |
| IDoFT (`TestingResearchIllinois/idoft`) | UIUC / mir.cs.illinois.edu | none — no LICENSE file | Informal citation request only, not a legal grant to reuse |

## Decision
**FlakeFlagger**, because IDoFT has no licence. A citation request is not a licence — it
does not grant permission to reuse the data, regardless of how convenient or directly
on-topic it is. For IDoFT to become usable, its maintainers would need to add an explicit
open licence to the repository.
